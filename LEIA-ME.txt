CIFRAMIX - Pot-pourri de cifras com transposição e rolagem automática
=====================================================================

COMO ABRIR NO WINDOWS (sem VS Code)
-----------------------------------
1. Extraia o ZIP em uma pasta (por exemplo, Documentos\CifraMix). Não abra de dentro do ZIP.
2. Opção simples: dê dois cliques em index.html (abre no navegador padrão; prefira Chrome ou Edge).
   Tudo funciona, exceto a instalação como aplicativo.
3. Opção com instalação (PWA): dê dois cliques em Iniciar-CifraMix.bat. Ele abre o app em
   http://localhost:8080 e deixa uma janela preta aberta (não feche enquanto usar).
   No Chrome/Edge aparece um ícone de instalar na barra de endereço. Depois de instalado,
   o app abre como programa próprio e funciona sem internet.
   (Esse .bat usa o PowerShell que já vem no Windows. Se o Windows pedir permissão, permita.)

IMPORTANTE: os dados ficam guardados no navegador, separados por endereço. O que você salvar abrindo
index.html direto NÃO aparece em http://localhost:8080, e vice-versa. Escolha um jeito e use sempre
o mesmo; para mudar, use Exportar JSON / Importar JSON (veja Backup).

COMO USAR NO CELULAR
--------------------
Opção A (mais simples, sem instalar): exporte seus repertórios no computador (Biblioteca -> Exportar JSON),
envie o arquivo para o celular (Drive, WhatsApp, e-mail) e abra o app no celular importando o arquivo.
Para o app em si funcionar no celular ele precisa estar em um endereço de internet:

Opção B (recomendada): publique a pasta em uma hospedagem estática gratuita (Netlify, GitHub Pages,
Cloudflare Pages ou similar). Você recebe um endereço https. Abra esse endereço no celular:
- Android (Chrome): menu ⋮ -> "Instalar app" (ou "Adicionar à tela inicial").
- iPhone (Safari): botão Compartilhar -> "Adicionar à Tela de Início".
Depois da primeira abertura com internet, o app abre também offline.
Seus dados continuam só no aparelho (a hospedagem guarda apenas os arquivos do app, não suas cifras).

BACKUP DOS REPERTÓRIOS
----------------------
- Biblioteca -> Exportar JSON: baixa ciframix-backup-AAAA-MM-DD.json com todas as músicas e pot-pourris.
- Biblioteca -> Importar JSON: restaura ou une com o que já existe (nada é sobrescrito).
- Guarde o arquivo fora do navegador (Drive, e-mail, pen drive). A tela Biblioteca mostra a data do último backup.
- Limpar dados do navegador ou desinstalar o app APAGA tudo que não foi exportado.

COMO USAR
---------
1. Pesquisar -> Cadastrar música: cole ou digite a cifra (acordes numa linha, letra na linha de baixo)
   e informe o tom, se souber. Também dá para importar um arquivo .txt.
   (O CifraMix não busca cifras na internet: não existe API pública autorizada do Cifra Club.
   Use apenas cifras suas ou que você tenha permissão para usar.)
2. Biblioteca -> Novo pot-pourri: adicione músicas, reordene (arraste ⠿ ou use ▲▼), ajuste o tom e anote.
3. Tocar pot-pourri: todas as músicas em uma página. Iniciar rola sozinho; Modo palco para tocar ao vivo.
Atalhos: Espaço pausa/continua | seta para cima/baixo velocidade | direita/esquerda troca de música | Esc sai do palco.

ESTRUTURA DOS ARQUIVOS
----------------------
index.html, manifest.webmanifest, sw.js (offline), css/, js/ (storage, ui, source-adapter, search,
chord-engine, transposer, navigation, autoscroll, setlist, presentation, help, app), assets/icons/, tests/.
Para adicionar uma fonte autorizada de cifras: crie uma classe que estenda SourceAdapter (js/source-adapter.js)
e registre com CM.registerSource(). Se alterar qualquer arquivo do app, aumente VERSION em sw.js.
